Legacy Codebase week!
Quantum Espresso
 - Computational Chemistry tool
 - CLI
 - Configure input -> run model -> view output logs -> visualize output
 - QE has some post-processing tools, but visualization happens externally

Feature Ideas:
 - Checkpoints and restarting (already present? maybe better handling?)
   - Realtime monitoring (same feature? different?)
   - Modify the SCF loop (e.g., PW/src/electrons.f90) to output intermediate results to a file or socket at each iteration, and implement a control mechanism to pause/resume via signals or input flags.
 - Snapshot to check while still running.
   - Same file?
 - Automated Parameter Optimization
   - Add a module to automatically optimize key input parameters (e.g., k-point grid, energy cutoffs) based on system size and desired accuracy. This reduces the trial-and-error process for beginners.
   - Modify the input parsing routines (e.g., Modules/read_input.f90) to include an optimization subroutine that iteratively tests convergence (e.g., for ecutwfc, k_points) and adjusts parameters before the main SCF calculation in PW/src/pwscf.f90.
 - Simplified Pseudopotential Management
   - Integrate a pseudopotential recommendation system within QE, suggesting the best pseudopotential (e.g., norm-conserving vs. ultrasoft) based on the material and calculation type.
   - Extend the pseudopotential handling module (e.g., Modules/upf.f90) to include a database query system that matches pseudopotentials to input parameters and stores metadata in a lightweight SQLite database linked to Fortran via a C-binding interface.
 - Embedded Visualization Data Output
   - Modify QE to output visualization-ready data formats (e.g., JSON or VTK) for crystal structures, charge densities, or band structures, reducing reliance on external post-processing tools.
   - Update output routines (e.g., PW/src/write_output.f90, PostProc/pp.f90) to include VTK/JSON export functions, leveraging Fortran’s I/O capabilities or linking to external libraries like VTKFortran.
 - Sanity checks
   - "You have an atom that is not bonded"
   - Not an error, but like "Is this what you intended?"
 - Gui
   - Edit file in GUI
   - button to launch viewer
   - pause/restart/snapshot commands
   - sanity checks
 - Containerization for easy deploy?
