## 2. Implement suggest_kpoint_grid() [done]
### Dependencies: 4.1
### Description: Code the k-point grid suggestion algorithm based on reciprocal lattice norms and target spacing as described in the PRD reference.
### Details:
• In parameter_optimization.f90 implement FUNCTION suggest_kpoint_grid(cell, spacing) RESULT(grid(3)) where spacing = 2π / cutoff_k.
• Extract lattice vectors from cell%alat, cell%bm.
• Compute reciprocal lattice vectors b1,b2,b3 and their norms.
• For each direction i: n_i = MAX(1, NINT(norm(b_i)/spacing)).
• Ensure n_i are odd when cell has inversion symmetry if optimize_kpoints%flags%require_gamma_centered.
• Emit VERBOSE output when io_global%ionode.
• Return integer array grid(3).

## 3. Implement test_cutoff_convergence() [done]
### Dependencies: 4.1
### Description: Create routine that loops over kinetic-energy cutoffs (30→120 Ry) running single-point SCF in dry-run mode until total-energy change ΔE falls below target_accuracy.
### Details:
• Implement FUNCTION test_cutoff_convergence(input_state, opt) RESULT(best_cutoff).
• Loop cutoff = 30,40,…,120 Ry while iter ≤ opt%max_iterations.
• For each cutoff: CALL scf_driver(input_state, cutoff, dry_run=.TRUE., energy=e(i)).
• After first step, compute ΔE = ABS(e(i)-e(i-1)); EXIT when ΔE < opt%target_accuracy.
• Return cutoff that satisfied criterion; if none, return last tested and flag warning.
• Store energies and cutoffs in local arrays; if io_global%ionode write a mini-table to output file.

## 4. Implement optimize_parameters() orchestrator [done]
### Dependencies: 4.2, 4.3
### Description: Combine k-point and cutoff optimisations under a single PUBLIC interface, update global simulation parameters, and respect SERIAL-only execution constraint.
### Details:
• Implement SUBROUTINE optimize_parameters(input_state, opt, out_grid, out_cutoff).
• IF(opt%optimize_kpoints) CALL suggest_kpoint_grid() and overwrite k_points input variables (kpoint_grid, kpoint_shift).
• IF(opt%optimize_cutoff) CALL test_cutoff_convergence() and overwrite ecutwfc/ecutrho (ecutrho=4*ecutwfc default).
• Perform validity checks: throw error if existing k_points defined with automatic optimisation.
• Wrap the whole routine with IF(.NOT.is_mpi_enabled()) to enforce serial-only; otherwise PRINT warning and RETURN without changes.
• Propagate chosen parameters to subsequent setup routines via USEd common modules or by updating input_state.
• Provide verbose summary block printed once with chosen grid and cutoff.
