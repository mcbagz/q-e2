# Subtasks:
## 1. Define configuration schema and default INI template [done]
### Dependencies: None
### Description: Create a formal list of configurable keys, their default values, data types, and acceptable ranges/severities for each sanity check. Provide a default INI string that will be written to ~/.qe/config.ini on first run.
### Details:
1. List every sanity check (distances, cell angles, isolated atoms, symmetry breaking) and associate keys such as distance.min, angle.max, isolation.radius, symmetry.tolerance, level.
2. Decide on global keys (log_level, prompt_on_warning, force_flag_name). Include allow_continue default.
3. Store the template as a CHARACTER(len=:), allocatable constant inside a small Fortran include file (e.g., sanity_config_defaults.inc) for easy write-out.
4. Document each key inline to enable later auto-generation of comments in the INI file.

## 2. Implement compact INI parser/serializer with optional INIH C backend [done]
### Dependencies: 8.1
### Description: Provide a Fortran-visible API capable of reading an INI file into a mapping structure and writing it back. Prefer a pure Fortran fallback using READ(unit,*) and simple section/key scanning, and enable optional linking against INIH via ISO_C_BINDING for performance.
### Details:
1. Define TYPE ini_kv_pair (CHARACTER(:), CHARACTER(:)) and TYPE ini_section containing an allocatable array of pairs.
2. Implement read_ini_pure(unit, sections) that line-scans, trims, ignores comments (# and ;) and fills data structures.
3. Add BUILD flag USE_INIH; if defined, provide INTERFACE to inih C functions ini_parse_string / ini_parse_file; wrap them into read_ini_inih.
4. Provide generic read_ini() that dispatches depending on build flag.
5. Implement write_ini(unit, sections) with aligned “key = value” formatting, preserving order.
6. Expose PUBLIC: load_ini(path, sections), save_ini(path, sections), get_value(section,key,default), set_value(section,key,val).

## 3. Develop sanity_config.f90 module [done]
### Dependencies: 8.2
### Description: Create the high-level configuration manager that loads ~/.qe/config.ini (or creates it) and exposes typed getters/setters to the rest of the codebase.
### Details:
1. NEW MODULE sanity_config; USE ini_parser_mod created in subtask 2.
2. On first call to load_sanity_config(), check existence of ~/.qe; mkdir if necessary; if file missing, write template from subtask 1.
3. After loading, perform type conversion: INTEGER, REAL(8), LOGICAL, or CHARACTER.
4. Provide PUBLIC: load_sanity_config(), save_sanity_config(), get_real(key), get_int(key), get_logical(key), get_string(key), set_* variants.
5. Implement cache to prevent repeated disk I/O; include flag config_loaded.
6. Offer helper get_check_threshold(check_name) returning threshold + severity level.

## 4. Implement individual sanity check routines in sanity_checks.f90 [done]
### Dependencies: 8.3
### Description: Write self-contained functions to evaluate each physical sanity criterion, using thresholds from sanity_config module.
### Details:
1. MODULE sanity_checks; USE sanity_config.
2. For each check:
   a) check_atomic_distances(structure) -> returns severity & message; compute pairwise distances, compare with distance.min.
   b) check_cell_angles(cell) -> evaluate angles vs angle.max/min.
   c) check_isolated_atoms(structure) -> graph analysis within isolation.radius.
   d) check_symmetry_break(structure) -> compare nominal lattice symmetry with atomic positions tolerance.
3. Define TYPE san_result (severity, message, suggestion).
4. Provide PUBLIC perform_all_checks(structure, cell, results(:)).

## 5. Create run_all_checks orchestrator with interactive prompt and force bypass [done]
### Dependencies: 8.4
### Description: Provide a high-level routine that invokes all checks, aggregates results, handles user prompting, and sets allow_continue flag for the caller.
### Details:
1. Add SUBROUTINE run_all_checks(structure, cell, allow_continue) to sanity_checks module.
2. Call perform_all_checks; sort results by severity (critical > warning > info).
3. If critical and NOT force flag (from config or future CLI), print summary and set allow_continue=.false.
4. For warning, prompt user via READ(*,*) unless prompt_on_warning=.false.; respect batch/non-interactive mode by checking INPUT_UNIT==F.
5. Respect global config log_level when printing.
6. Return logical so caller can decide to exit or proceed.
