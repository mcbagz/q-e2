## 4. Implement soft-pause handling and graceful shutdown [done]
### Dependencies: 3.2
### Description: Add logic so that if local_soft is .TRUE. when entering an iteration, the code writes a checkpoint at the END of that iteration and exits via stop_run(.FALSE.).
### Details:
• In main SCF loop declare logical :: pause_after_iter = .FALSE.
• Immediately after CALL handle_signal_requests set pause_after_iter = soft_pause_requested (read once more in CRITICAL).
• At very end of the iteration (just before END DO or cycle increment):
   IF(pause_after_iter) THEN
      fname = generate_checkpoint_filename()
      CALL write_checkpoint(fname, iter, etot, conv)
      IF (ionode) WRITE(io_global,*) "Soft pause requested – checkpoint written to",TRIM(fname)
      !$OMP CRITICAL(clear_soft)
      soft_pause_requested = .FALSE.
      !$OMP END CRITICAL(clear_soft)
      CALL stop_run(.FALSE.)
   END IF
• Ensure stop_run import via USE io_global or existing module.
