## 3. Implement --config key=value processing and persistence [done]
### Dependencies: 9.1
### Description: Apply configuration overrides supplied on the CLI and persist them through sanity_config module.
### Details:
• In setup.f90 after CLI retrieval, iterate over cfg_pairs array.
• For each entry split on first '=' to obtain key & value strings.
• CALL set_config_value(TRIM(key), TRIM(value)) from sanity_config module (delivered by Task 8).
• After all overrides, CALL save_sanity_config() so the updated INI is written (ensure file locking for MPI root only; other ranks skip save).
• Handle malformed entries (no '=' or empty key) with fatal error before any heavy initialisation.

## 4. Wire sanity-check execution flow into setup based on CLI flags [done]
### Dependencies: 9.2, 9.3
### Description: Call load_sanity_config, execute run_all_checks(), and control continuation/early exit according to --ignore-sanity-checks, --sanity-checks-only, and --force.
### Details:
• At the start of setup.f90, CALL load_sanity_config().
• If ignore_checks .TRUE. THEN set logical can_continue=.TRUE. and skip run_all_checks().
• ELSE CALL run_all_checks(can_continue) from sanity_checks module.
• When can_continue=.FALSE. AND .NOT. force_checks THEN gracefully STOP with informative banner.
• If checks_only .TRUE. THEN after successful checks (regardless of force/ignore) STOP without entering the normal computation loop.
• Make sure force_checks overrides can_continue but not checks_only.
• Return proper exit status codes (0 success, 2 aborted by failed sanity).

## 5. Ensure single MPI prompt and broadcasted user decision [done]
### Dependencies: 9.4
### Description: Modify run_all_checks and supporting routines so that only MPI root rank prompts the user and the answer is broadcast via MPI_BCAST to all ranks.
### Details:
• Guard interactive prompts with IF (my_rank==root) THEN ... to collect response (Y/N).
• Convert character response to integer flag (0=no continue,1=continue) and CALL MPI_BCAST(flag,1,MPI_INTEGER,root,MPI_COMM_WORLD,ierr).
• All ranks set can_continue = (flag==1).
• For non-interactive runs (batch, checks_only, or force_checks) skip prompting completely to avoid deadlocks.
• Update any existing prompt utilities to accept communicator argument or rely on global communicator.
• Verify behaviour under both OpenMPI and Intel MPI.
