# Quantum ESPRESSO Module Documentation Index

This directory contains comprehensive documentation for all major modules in the Quantum ESPRESSO suite. Each documentation file provides detailed information about the module's purpose, structure, key components, and dependencies.

## Core Computational Modules

### Electronic Structure Calculations
- **[PW](PW.md)** - Plane Wave Self-Consistent Field (PWscf) - The main DFT engine
- **[CPV](CPV.md)** - Car-Parrinello molecular dynamics implementation
- **[atomic](atomic.md)** - Atomic calculations and pseudopotential generation

### Linear Response and Phonons
- **[PHonon](PHonon.md)** - Density Functional Perturbation Theory for phonons and dielectric properties
- **[TDDFPT](TDDFPT.md)** - Time-dependent DFPT for optical spectra and excitations
- **[LR_Modules](LR_Modules.md)** - Shared linear response routines

### Advanced Electronic Structure Methods
- **[GWW](GWW.md)** - GW many-body perturbation theory implementation
- **[HP](HP.md)** - Hubbard parameter calculations using DFPT
- **[KCW](KCW.md)** - Koopmans-compliant functionals with Wannier functions

### Transport and Spectroscopy
- **[EPW](EPW.md)** - Electron-phonon coupling and carrier transport
- **[PWCOND](PWCOND.md)** - Ballistic quantum transport calculations
- **[QEHeat](QEHeat.md)** - Thermal transport and energy current calculations
- **[XSpectra](XSpectra.md)** - X-ray absorption spectroscopy

### Post-Processing and Analysis
- **[PP](PP.md)** - Post-processing tools for visualization and analysis
- **[NEB](NEB.md)** - Nudged Elastic Band for transition states and reaction pathways
